# 사용자 검수와 시연 참고

## 검수 순서

- [ ] 로컬 주소에서 세 칸과 실제 영상 목록이 보인다.
- [ ] 영상 링크를 넣으면 영상이 추가된다.
- [ ] 선택한 영상의 고민·근거·댓글이 서로 맞는다.
- [ ] 40~120자이며 링크·해시태그·꾸민 이용 후기가 없다.
- [ ] 다른 영상의 초안이 해당 영상의 표현을 반영한다.
- [ ] 시작 시 OS 기본 브라우저로 검수 페이지가 열리며 프로필 설정에 감지된 브라우저가 표시된다.
- [ ] 기본 브라우저의 전용 창을 열고 직접 로그인할 수 있다. Safari·Firefox 등에서는 게시 연결 제한이 보인다.
- [ ] 로그인 완료 · 연결을 누르면 검증된 macOS 전용 창만 정상 종료하고 같은 프로필의 계정을 확인한다. Windows는 먼저 직접 종료한다.
- [ ] 이미 열린 전용 로그인 창을 다시 표시할 수 있고 버튼 아래에 진행·실패 이유가 유지된다.
- [ ] Google 로그인 성공과 YouTube 채널 준비 필요 상태가 구분된다.
- [ ] OS 기본 브라우저 변경 후 다시 감지하면 이전 연결 완료 상태가 해제되고 다른 브라우저 프로필과 섞이지 않는다.
- [ ] 한국어 화면에 한 글자씩 입력·게시·내 댓글 확인이 보인다.
- [ ] 같은 영상의 재게시가 차단된다. 결과 불명 상태에서 자동 재게시하지 않는다.
- [ ] 실패 이유·화면 캡처·프로필·시간·댓글이 기록된다.
- [ ] 서로 다른 계정 3개 선택과 순환 배정이 동작한다.
- [ ] 유망 영상 관측은 실제 스냅샷을 사용하고 초안에서 끝난다.

검수 완료 전에는 시연 영상 제작을 시작하지 않습니다. 로그인·댓글 게시·장기 실측이 필요한 항목은 확인 전까지 미검증으로 남깁니다.

## 검수 완료 후 사용할 2~3분 구성

| 시간      | 보여줄 것                    | 설명의 요점                                       |
| --------- | ---------------------------- | ------------------------------------------------- |
| 0:00~0:15 | 대시보드 세 칸               | 맥락 → 초안 → 실제 게시와 확인                    |
| 0:15~0:40 | 영상 불러오기·선택           | 실제 영상 메타데이터와 자료 수집                  |
| 0:40~1:10 | 고민·근거·초안 검수          | 영상 고유 표현, 자연스러운 운명원 관심, 제약 검사 |
| 1:10~1:55 | 크롬 프로필·타이핑·게시·확인 | 실제 경로를 끊지 않고 보여주기                    |
| 1:55~2:20 | 운영 기록·중복 차단          | DB에서 강제하는 영상당 1개와 하루 상한            |
| 2:20~2:45 | 가점과 제작 의도             | 프로필 배정·링크·즉석 생성·초안 전용 탐색         |

원본 키·개인 인증 화면은 녹화하지 않습니다. 시연은 실제 성공과 미검증 상태를 구분합니다. 로그인 없이 재생되는 Drive 또는 YouTube 공유 링크를 준비합니다.
