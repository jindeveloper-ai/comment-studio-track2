# Track 2 요구사항·동작·보안 점검

점검 기준은 사용자가 제공한 7쪽 과제 PDF와 대화에서 확정한 운영 규칙입니다. 새로 지정한 PDF도 기존 PDF와 파일 해시가 동일함을 확인했습니다. 2026-11-03~04에 macOS의 설치된 Chrome, 실행 중인 로컬 서버, 실제 Vertex 인증 및 실제 YouTube 계정으로 확인했습니다. 아래에서 실제 서비스 테스트와 자동 테스트를 구분합니다.

## 실제 댓글 정리 결과

사용자가 삭제 직전에 두 댓글의 영상·작성 프로필·본문을 보고 ‘두 개 모두 영구 삭제’를 승인했습니다. 새 테스트 댓글은 실제 삭제 메뉴를 실행한 뒤 화면에서 사라졌으나, 최초 구현은 완료 알림을 찾지 못해 ‘삭제 확인 필요’로 잠갔습니다. 기존 댓글은 최신순 및 추가 로딩으로 검색해도 정확한 댓글을 찾지 못해 다른 댓글을 삭제하지 않았습니다.

두 작성 프로필의 공식 YouTube 댓글 기록을 다시 확인한 결과 모두 ‘활동 없음’이었습니다. 현재 두 기록은 **‘댓글 없음 확인’**으로 표시합니다. 이는 삭제 성공 응답을 직접 받은 **‘댓글 삭제 완료’**와 구분되며, 삭제·플랫폼 처리 등 없어지게 된 원인을 단정하지 않습니다. 재게시 제한과 게시 기록은 유지합니다. 실제 사이트 변경으로 댓글이 보이지 않거나 확인 결과가 불명확하면 재삭제하지 않습니다.

## 코드 리뷰로 수정한 항목

- 동일 영상에서 계정을 바꿔도 버튼이 꺼지는 이유를 명확히 표시하고, 초안 되돌리기 후 다른 영상·다른 연결 프로필을 준비하는 흐름을 추가했습니다.
- ‘다시 생성’ 아이콘을 유지하며 버튼 배경·테두리·포커스를 강조했습니다.
- 수정한 동일 댓글의 다른 영상 재사용을 서버에서 차단했습니다.
- 영상별 하루 초안 요청 상한을 DB에 보존하고, 이전 편집의 늦은 검증 응답이 최신 입력을 덮지 않게 했습니다.
- 유망 영상의 증가량 149.x가 반올림으로 조건을 통과하지 않도록 수정했습니다.
- 영상 상세 조회 실패 시 남은 후보를 더 확인하도록 수집 여유를 늘렸습니다.
- 댓글 삭제는 ID·계정·본문을 모두 비교하고, 삭제 직전 확인창을 거칩니다. 계정 변경·동시 작업·중복 삭제·재시작 중단을 제한합니다.
- 삭제 결과는 성공 응답 또는 완료 표시와 대상 소멸로 확인하고, 불명확한 결과는 잠급니다. 공식 댓글 기록이 비어 있는 경우는 ‘댓글 없음 확인’으로 별도 기록합니다.
- 전용 YouTube 프로필의 언어가 영어로 저장된 경우를 발견해 한국어 표시 언어 확인을 추가했습니다. 댓글 정렬 메뉴의 부가 설명과 숨겨진 항목 때문에 검색이 실패하던 선택자도 수정했습니다.
- OSV 검사에서 발견한 `body-parser` 2.3.0의 고위험 서비스 거부 취약점을 2.4.0으로 갱신했습니다. [공식 보안 권고](https://github.com/expressjs/body-parser/security/advisories/GHSA-27r3-jxmh-p828)

## 공개 전 보안과 검증 범위

인증 JSON은 저장소 밖에, 참조 경로는 무시되는 로컬 `.env`에만 둡니다. `.env` 600, `.local` 700 권한을 확인했습니다. 공개 대상 52개 파일과 빌드 결과 3개 파일에서 실제 인증 값·키 ID·서비스 계정 주소·인증 파일 경로의 일치를 검사했고 0건이었습니다. 이후 추가 문서도 최종 공개 검사 대상으로 포함합니다. 비밀 값 원문이나 토큰은 출력하지 않았습니다.

커밋 훅은 실제 Git 인덱스의 바이트를 검사하며, 강제로 등록한 인증 JSON·쿠키·DB·압축 파일·심볼릭 링크와 과거 이력의 비밀 파일도 차단하도록 테스트합니다. 로그인 프로필·쿠키·운영 DB·원본 캡처는 `.local`에 보관하고 Git에서 제외합니다. Gitleaks 출력은 원문을 노출하지 않도록 숨겨 처리합니다. GitHub에는 아직 업로드하지 않았고, 원격 CI 실행 성공을 주장하지 않습니다.

실행한 검사: 변경 파일 `prek`, 프로젝트 lint, TypeScript 검사 포함 build, native test(102개), Gitleaks 포함 공개/이력 검사, Semgrep(74규칙), OSV-Scanner(275 패키지). 패치 후 OSV 0건, 수행한 Semgrep 검사 0건입니다. 마지막 실행 결과를 완료 시 다시 확인합니다. 의존성 버전과 공개 파일이 바뀌면 해당 검사를 다시 실행해야 합니다.

실제 OS 검증은 macOS Chrome 범위입니다. Windows/Linux는 감지·실행 분기의 모의 응답 테스트이며 실제 로그인·게시 검증은 하지 않았습니다. Safari/Firefox 등은 게시 자동화 미지원 안내가 나옵니다. Google 로그인 허용, YouTube 게시 가시성·조정, 영상 수집 결과는 외부 상태의 영향을 받습니다. 이 점검은 검사한 범위의 결과이며 모든 환경에서 버그나 유출 가능성이 절대 없다는 보장은 아닙니다.
