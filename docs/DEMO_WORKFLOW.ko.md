# 후속 작업: 시연 영상 촬영·편집

현재 요구사항 점검·버그 수정·댓글 정리·공개 전 보안 검사 이후에 진행할 사용자 지정 순서입니다. 사용자 검수 완료 전 촬영·TTS 생성·최종 편집을 시작하지 않습니다. 과제 PDF의 필수 제출 영상은 2~3분이며, 세 칸 사용→전용 Chrome→글자별 입력→게시→내 댓글 확인을 모두 담아야 합니다.

| 단계                       | 준비할 결과                                                                                                                                                                                                                                                                                                                                                      | 다음 단계 진행 조건                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 1. 영상 내용·TTS 대본 기획 | 2~3분 장면 순서, 실제 동작 근거, 한국어 내레이션 대본, 제작 의도. 필수 게시 경로를 중심으로 운영 제한·가점은 짧게 배치                                                                                                                                                                                                                                           | 사용자에게 기획과 검수 방법 제공                                    |
| 2. 검수 사이트 제시        | 실제 실행 중인 로컬 사이트와 기획·대본 검수 화면. 댓글·계정·근거·표시 상태를 직접 검수할 수 있게 구성                                                                                                                                                                                                                                                            | 사용자의 명시적 사이트/기획 검수 통과                               |
| 3. OBS 촬영                | macOS 컴퓨터 제어로 OBS의 지정 창/장면을 준비하고 실제 시연 촬영. Google 인증 화면·개인 파일·인증 설정·키·토큰·쿠키는 녹화에 포함하지 않음                                                                                                                                                                                                                       | 촬영본과 재생 가능한 검수 화면 제공                                 |
| 4. 촬영 영상 검수          | 촬영본을 검수 사이트에서 재생하고 사용자 피드백 반영                                                                                                                                                                                                                                                                                                             | 사용자의 촬영본 검수 통과                                           |
| 5. Vertex TTS·자막         | 듣기 편한 한국어 여성 화자. 요청 모델 `gemini-3.8-flash-tts`의 실제 Vertex 지원과 프로젝트 권한을 공식 문서/연결 검사로 먼저 확인. Vertex 서비스 계정 인증 및 `aiplatform.googleapis.com` 경로만 사용. Gemini Developer API나 별도 API 키 과금 경로로 자동 전환하지 않음. 승인된 대본으로 음성 생성·삽입, 일반적인 하단 YouTube 자막 형태와 타이밍으로 자막 추가 | 지원 모델이 없거나 권한이 부족하면 생성 전 확인. 작업본 사용자 검수 |
| 6. 사용자 재검수 후 컷편집 | 검수 통과 뒤 진행에 불필요한 대기·반복·실수 부분을 컷편집. 필수 타이핑·게시·댓글 확인 근거를 보존하고 TTS/자막 타임라인을 다시 맞춤                                                                                                                                                                                                                              | 최종 2~3분 및 재생·음량·자막 확인                                   |

시연의 설명 흐름은 ‘버튼 클릭→서버 검증→AI 또는 Chrome 작업→DB 기록→화면 갱신’으로 통일합니다. Node.js 24·TypeScript·React/Vite·Express·SQLite·Playwright를 선택한 이유와 실제 코드의 연결은 `CODE_WALKTHROUGH.ko.md`를 기반으로 최종 구현에 맞게 업데이트합니다.

OBS 권한과 설치 상태는 촬영 준비 시 실제 Mac에서 확인합니다. 기록을 위해 새 댓글이 필요하면 영상과 계정·본문을 먼저 준비하며, 영상당 1개·KST 하루 상한을 지킵니다. 삭제가 필요한 경우 해당 댓글을 특정하여 삭제 시점에 확인합니다. 검수 승인·촬영 완료·TTS 완료는 실제 수행 전 완료로 표시하지 않습니다. 영상 업로드와 제출은 별도로 요청받기 전 실행하지 않습니다.
